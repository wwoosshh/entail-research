### 🐛 Describe the bug

`ExampleHiddenStatesConnector` produces NaN hidden states when used with `extract_hidden_states` method on models with heterogeneous attention (e.g., Qwen3.5 which mixes linear_attention and full_attention layers).

The CacheOnlyAttentionLayer's slot_mapping is always zero. The block table GPU tensor for the hidden-states KV cache group is never populated with actual block IDs by `_compute_slot_mapping_kernel`. All token hidden states are written to KV cache slot 0 via `unified_kv_cache_update`, while `extract_from_kv_cache` reads from the request's actual block IDs — which point to unwritten (uninitialized) cache locations containing NaN/garbage.

Added a reproduction script, including comparison between transformers output and vllm's.
